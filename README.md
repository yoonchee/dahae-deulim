# 다해드림 — 시범 운영 페이지

어르신 생활 대행 서비스 **다해드림**. 지금은 직접 처리하는 무료 시범 운영입니다.

전화번호: **010-3990-0935**

## 핵심 가정

성인 자녀(또는 어르신 본인)는 전화하거나 연락처를 남겨, 일상 일을 실제로 부탁한다.

## 무엇을 보나

| 신호 | 잘 되고 있다 | 다시 생각해야 한다 |
| --- | --- | --- |
| 전화 또는 페이지 부탁 | 실제 일이 들어온다 | 페이지는 읽히지만 부탁이 없다 |
| 부탁 대상 | 자녀가 부모님을 위해 맡긴다 | 본인만 남거나 장난만 있다 |
| 고른 일 | 한두 가지에 수요가 몰린다 | 전부 비슷하거나 아무도 고르지 않는다 |

페이지에서 남긴 부탁은 로컬 `data/`에만 저장됩니다. `/results.html`에서 봅니다.

## 실행

```bash
npm start
```

브라우저에서 [http://localhost:3456](http://localhost:3456) 을 엽니다.
